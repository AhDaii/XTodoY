# XTodoY

轻量、常驻后台的 PC 桌面待办软件。

- 待办事项记录，单选框手动勾选完成
- 事项时间与循环规则，可设置提醒时间，通过系统通知提醒
- 多级标签与标签管理，按标签分类浏览
- 低 CPU / 内存占用的托盘常驻，悬浮窗显示今日待办数量，点击回到主界面
- 每天 / 每周 / 每月完成统计
- 浅色 / 深色 / 跟随系统主题

技术栈（规划）：Electron + electron-vite + React + TypeScript + Tailwind CSS + SQLite（better-sqlite3）
