# XTodoY 用户手册

> 适用版本：v1.0 · XTodoY 是一个轻量、常驻后台的桌面待办软件：记下要做的事，到点提醒，桌面上随时能看到今天还剩几件。

## 1 安装

从 [Releases 页面](https://github.com/AhDaii/XTodoY/releases) 下载对应平台的安装包。

| 平台 | 下载 | 说明 |
|---|---|---|
| Windows 10 / 11（64 位） | `XTodoY-Setup-<版本>.exe` | 双击安装，只安装到当前用户，不需要管理员权限。首次运行时 Windows 可能提示"Windows 已保护你的电脑"（安装包暂未签名），点「更多信息」→「仍要运行」 |
| macOS 12+ | `XTodoY-<版本>-mac-arm64.dmg`（Apple 芯片）/ `-mac-x64.dmg`（Intel） | 打开 DMG，把 XTodoY 拖到"应用程序"。首次打开会提示无法验证开发者：到"系统设置 › 隐私与安全性"中点「仍要打开」 |
| Linux（64 位） | `XTodoY-<版本>-linux-x86_64.AppImage` 或 `.deb` | AppImage 加执行权限后直接运行（`chmod +x`），可在程序内自动更新；deb 用 `sudo apt install ./XTodoY-….deb` 安装 |

> macOS 与 Linux 为次要平台：主要功能可用，个别细节（如通知按钮）取决于系统支持。

## 2 界面一览

- **左侧栏**：今天 / 计划 / 全部 / 已完成 / 回收站 五个视图，下面是标签树；底部是统计、标签管理、设置，以及收起侧边栏（`Ctrl+B`）。
- **中间列表**：顶部输入框快速新建，回车保存；单击事项打开右侧详情。
- **右侧详情**：修改标题、日期时间、循环、提醒、标签、优先级、备注；修改即时保存，`Esc` 关闭。
- **悬浮窗**：桌面上的小日历页，显示今天的日期、今天还没完成的事项数和今日进度，单击打开主窗口。
- **托盘图标**（macOS 为菜单栏图标）：程序在后台运行时一直在这里，右键打开菜单。

## 3 待办

| 操作 | 方法 |
|---|---|
| 新建 | 在列表顶部输入框输入标题，回车；在"今天""计划"中新建的事项默认今天到期，在标签视图中新建的自动挂上该标签。任何时候按 `Ctrl+N` 都可以直接开始输入 |
| 完成 | 单击事项前的圆圈；屏幕底部会出现"撤销"，5 秒内可以撤销 |
| 编辑 | 单击事项打开详情面板 |
| 删除 | 详情面板中删除，或选中事项按 `Delete`；删除的事项在回收站保留 30 天，可以恢复 |
| 搜索 | `Ctrl+F`，按标题和备注查找 |
| 优先级 | 详情面板中设置高 / 中 / 低；圆圈颜色随优先级变化 |

**五个视图**

- **今天**：今天到期的事项（逾期的不算在内，顶部会提示有几项逾期）。
- **计划**：所有有日期的未完成事项，按 逾期 / 今天 / 明天 / 本周 / 以后 分组。
- **全部**：所有未完成事项，有日期的在前。
- **已完成**：按完成日期分组。
- **回收站**：删除的事项，可恢复或永久删除。

**排序**：今天、计划、全部和标签列表右上角可以选择 按截止时间 / 手动排序 / 按优先级 / 按创建时间 / 按标题，每个列表分别记住。选"手动排序"后可以拖动事项调整顺序（只能在同一分组内），也可以选中后按 `Alt+↑` / `Alt+↓`。

## 4 日期、时间与循环

- 在详情面板中单击"日期"设置截止日期；关闭"全天"可以设置具体时间。
- 单击"循环"设置重复：每天 / 每个工作日 / 工作日第一天 / 每周（可选星期几）/ 每月（可选几号或最后一天）/ 每年，以及间隔（每 2 周……）和结束条件（永不 / 某日 / 若干次）。面板下方会预览接下来 5 次的日期。
- **每个工作日**按中国大陆法定节假日与调休计算：放假的日子跳过，调休上班的周末照常提醒。**工作日第一天**只在休息之后的第一个工作日出现——平时是周一，长假后是上班第一天。预览中会标出"国庆节后""调休上班"等说明。
- 节假日数据来自 [holiday-cn](https://github.com/NateScarlet/holiday-cn)，程序内置往年与本年的安排，并每周联网获取最新安排（下一年的安排通常在 11 月公布）；可在设置 › 通用中关闭"自动更新节假日"。没有某年安排时按周一至周五计算。
- 每月 31 号的事项在小月会落在当月最后一天。
- 循环事项勾选完成后会自动变成下一次；不想做这一次可以在详情中选"跳过本次"。

## 5 提醒

- 带时间的事项新建后会自动加上"准时"提醒（可在设置中修改默认提醒）。
- 详情面板中单击"提醒"可以添加 准时 / 提前 5、15、30 分钟 / 提前 1、2 小时 / 提前 1 天（全天事项为 当天 / 提前 1 天 / 提前 2 天），也可以自定义提前量或指定某个具体时刻；每个事项最多 5 个提醒。
- 全天事项的提醒在 **08:30** 发出（设置 › 提醒中可修改）。
- 提醒通过系统通知弹出，可以直接点「完成」或「稍后提醒」（默认 10 分钟后再提醒）。
- 电脑睡眠期间错过的提醒，唤醒后会补发（只补 24 小时内的；超过 3 条会合并成一条）。
- 需要专心时，可以在托盘菜单或设置中**暂停提醒** 1 小时或到明天，暂停结束后补发期间的提醒。
- 已完成的事项不会再提醒。

> 如果收不到通知：检查系统是否关闭了 XTodoY 的通知（设置 › 提醒中会显示状态，并提供「打开系统设置」），以及是否开启了勿扰 / 专注模式。可以在设置 › 提醒中点"测试系统通知"试一下。

## 6 标签

- 标签可以分多级（最多 5 级），例如"工作 / 项目A / 设计"；每个事项最多 10 个标签。
- 单击左侧标签树中的标签查看该标签下的事项，可切换"包含子标签 / 仅本标签"和"显示已完成"。
- **标签管理**（左下角）：新建、重命名（`F2`）、改颜色、删除（`Delete`）、合并到另一个标签；拖动一行到另一个标签上可以调整层级。删除标签时可以选择把子标签上移一级或一并删除，事项本身不会被删除。

## 7 统计

左下角「统计」查看完成情况，可在 日 / 周 / 月 之间切换，左右箭头翻看以前的周期：

- 摘要：本期完成数（与上期同期比较）、到期完成率、连续完成天数。
- 日：按小时的分布和完成时间线；周：每天完成数的趋势线（虚线为前一周）；月：日历热力图。
- 按标签分布：单击某个标签可以看到它下一级子标签的分布。
- 完成明细：单击标题跳转到该事项。

## 8 悬浮窗与后台运行

- 关闭主窗口后程序继续在后台运行，提醒照常；从托盘图标或悬浮窗重新打开。想彻底退出，用托盘菜单的"退出"（或在设置中把关闭行为改成"退出程序"）。
- 悬浮窗可以拖到任意位置（不会被拖出屏幕），靠近屏幕边缘松开时会自动贴边，位置会被记住；右键菜单可以新建待办、锁定位置、调整透明度或隐藏。
- **全局快捷键**：在任何程序里按 `Ctrl+Alt+T`（macOS 为 `⌘⌥T`）打开 XTodoY 并直接新建待办；设置 › 通用中可以换成别的组合或关闭。
- 设置 › 通用中可以开启**开机自启**（启动后只显示托盘和悬浮窗）。

## 9 设置与数据

- **外观**：浅色 / 深色 / 跟随系统；硬件加速（默认关闭，开启后滚动和动画更流畅，但多占一些内存，重启后生效）。
- **数据**：
  - 「导出」把全部事项、标签、提醒、完成记录和设置保存为一个 JSON 文件；「导入」用这样的文件覆盖当前数据（覆盖前会自动备份）。
  - 程序每天第一次启动时自动备份数据库，保留最近 7 份。
  - 「打开数据目录」可以看到数据库、备份（backups）和日志（logs）。数据目录位置：Windows `%APPDATA%\XTodoY\data`，macOS `~/Library/Application Support/XTodoY/data`，Linux `~/.config/XTodoY/data`。
- **数据仅保存在本机**，不会上传；除了检查更新和获取节假日安排（都只读取公开文件，可分别关闭），程序不会联网。
- 如果数据库文件损坏，启动时会提示从最近的备份恢复，损坏的文件会保留在数据目录的 corrupt 文件夹中。

## 10 更新

- 默认每天自动检查一次新版本（只读取 GitHub 上的版本信息，不发送任何数据）。有新版本时，设置左侧出现小圆点，托盘菜单顶部也会提示。
- Windows 与 Linux AppImage：新版本在后台下载，下载完成后可以「立即重启并更新」，或者什么都不做——下次退出程序时自动安装。安装前会自动备份数据。
- macOS 与 Linux deb：程序会提示新版本，点「前往下载页」下载安装。
- 可以"跳过此版本"，也可以在设置 › 更新中关闭自动检查、自动下载，或切换到测试版通道。

## 12 常见问题

- **通知不弹出**：见 §5 的说明；Windows 上还可以检查"设置 › 系统 › 通知"中 XTodoY 是否开启。
- **悬浮窗不见了**：托盘菜单中勾选"显示悬浮窗"；如果它在已经拔掉的显示器上，重启程序后会回到主屏幕右下角，也可以在设置中「重置位置」。
- **想在另一台电脑上使用**：在原电脑上导出，新电脑上安装后导入。
- **卸载**：Windows 在"设置 › 应用"中卸载；卸载不会删除数据目录，如需彻底清除请手动删除 §9 中的目录。
- **反馈问题**：到 [GitHub Issues](https://github.com/AhDaii/XTodoY/issues) 提交，附上数据目录 logs 中的 main.log 会更容易定位。
