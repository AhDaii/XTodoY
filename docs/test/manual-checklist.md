# XTodoY 人工测试清单（v1.0.0-rc）

> 自动化测试覆盖不到、需要真机或会改动系统设置的项目。用例编号在 [traceability.md](traceability.md) 中引用。
> 每项记录：测试人、日期、环境（系统版本 / 缩放 / 显示器）、结果（✅ / ❌ + 问题链接）。
> 默认在 **Windows 安装版**（NSIS 安装包）上执行；标注 [Mac] / [Linux] 的在对应平台执行。

## 系统集成

| 编号 | 项目 | 步骤 | 期望 | 结果 |
|---|---|---|---|---|
| M-01 | 通知按钮（FR-REM-04） | 新建 2 分钟后到期的事项；通知出现后分别点「完成」「稍后提醒」；再点通知正文 | 「完成」后事项变为已完成；「稍后提醒」10 分钟后再次通知；点正文打开主窗口并定位到该事项。程序未运行时点按钮也能生效 | |
| M-02 | 开机自启（FR-BG-05） | 设置中开启开机自启，重启电脑 | 登录后只出现托盘与悬浮窗，不弹主窗口；关闭后重启不再启动 | |
| M-03 | 休眠补发（FR-REM-07） | 新建 5 分钟后提醒的事项，让电脑睡眠 10 分钟后唤醒 | 唤醒后 5 秒内补发；超过 3 条时合并为一条；跨零点后悬浮窗日期与计数刷新 | |
| M-04 | 高 DPI（NFR-USE-05） | 系统缩放分别设为 100% / 125% / 150% / 200% | 主窗口、悬浮窗、托盘图标清晰，无错位、无截断；待办前的勾选框圆圈粗细均匀、不发虚（#30） | |
| M-05 | Windows 10（2.4） | 在 Windows 10 22H2 上安装并完成 M-01、M-02 | 与 Windows 11 一致 | |
| M-06 | 通知被关闭（FR-REM-09） | 系统设置 › 通知中关闭 XTodoY；回到程序 | 主窗口顶部与设置 › 提醒显示"已关闭"，「打开系统设置」跳到通知设置；重新开启后提示消失 | |
| M-07 | 切换时区（FR-REC-08） | 新建每天 9:00 循环提醒；把系统时区改为东京（+9） | 1 分钟内提醒时间按东京 9:00 重算；改回后恢复 | |
| M-08 | 多显示器（FR-FLT-04） | 把悬浮窗拖到副显示器，退出；拔掉副显示器后启动 | 悬浮窗回到主显示器右下角（距边缘 24 px） | |
| M-09 | 单实例（FR-BG-04） | 程序运行时再次双击图标 | 不启动第二个实例，已有实例的主窗口被激活 | |
| M-28 | 窗口背景图（FR-SET-10，#41） | 分别选择 6 个内置背景，并上传一张 4K 风景照；浅色 / 深色主题下各看一遍今天、统计、设置页；拖动窗口边缘缩放、快速滚动列表 | 列表文字清晰可读；暗化 / 面板不透明度调到最低时仍能分辨；缩放与滚动无明显卡顿（硬件加速关闭时）；重启后背景保持；选择"无"恢复原样 | |
| M-27 | 界面音效（FR-SET-09，#37） | 在设置 › 通用中逐个切换 4 种风格并调节音量；回到列表新建、完成、完成最后一项、撤销、删除 | 每个时刻声音可分辨、不刺耳；连续快速勾选不叠成噪音；音量 0% 与关闭开关时完全无声；蓝牙耳机等外设切换后仍能发声 | |
| M-26 | 安装向导（IR-10，#29） | 卸载后运行安装包：选"仅为我"，把位置改为 D:\Apps，取消"创建桌面快捷方式"，完成并运行 | 安装到 D:\Apps\xtodoy；桌面无快捷方式、开始菜单有；通知正常；任务栏图标为 XTodoY（#23）；之后程序内更新仍装在原位置且不新建桌面快捷方式 | |

## 更新（需要两个真实发布版本）

| 编号 | 项目 | 步骤 | 期望 | 结果 |
|---|---|---|---|---|
| M-10 | 真实升级（FR-UPD-02~07、11） | 安装 v1.0.0-rc.1（预发布版会自动获取预发布更新，无需切换通道）；发布 rc.2 后在设置 › 更新中检查 | 后台下载完成后提示就绪；①「立即重启并更新」30 秒内启动新版本，显示"已更新到"横幅；② 另测一次选择稍后、退出程序，再启动即为新版本。两种方式下事项、标签、提醒、完成记录、设置、悬浮窗位置不变；backups 中有 pre-update 备份 | |
| M-11 | 失败场景（FR-UPD-05、09，NFR-REL-05） | ① 下载过程中断网 ② 用代理篡改下载的安装包 ③ 安装时占用安装目录文件 | ① 显示无网络，恢复后可重试完成 ② 校验失败、删除安装包、当前版本可用 ③ 当前版本可正常启动、数据完整，日志 logs/main.log 有原因 | |
