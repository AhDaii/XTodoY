# XTodoY 设计系统 v1.8

> 阶段：P2 界面原型 · 依据：[SRS v1.1](../docs/srs/SRS.md) · 工具：ui-ux-pro-max
> 令牌源文件：[`tokens.css`](tokens.css)（前端直接引用）· 原型：[`prototype/index.html`](prototype/index.html)、[`prototype/system.html`](prototype/system.html)

## 1 设计方向

| 项 | 结论 | 来源 |
|---|---|---|
| 产品类型 | Productivity Tool（个人效率工具，桌面端） | ui-ux-pro-max `--design-system` |
| 视觉风格 | **Minimalism & Swiss Style**：留白、清晰层级、网格对齐、功能优先、无装饰性元素 | 同上（Light / Dark 均支持，可访问性风险低） |
| 关键词 | 专注、安静、低干扰、可扫读 | 产品定位 |
| 动效 | 克制（Motion 3/10）：仅用于状态反馈与空间连续性，150–300 ms | 设计刻度 `--motion 3` |
| 密度 | 标准偏紧凑（Density 7/10）：桌面列表需一屏展示更多事项 | 设计刻度 `--density 7` |

**避免**：复杂引导流程、拟物质感、渐变与玻璃拟态、emoji 作图标、仅靠颜色传达状态、装饰性动画。

## 2 颜色

> v1.1（评审意见）：原 Teal 方案的浅色主题偏灰，改为**蓝色系**。

配色参考 ui-ux-pro-max 的蓝色系方案（Productivity / B2B Service：`Blue 600` 主色 + 极浅蓝背景 + Slate 文字），为桌面端与 WCAG AA 做了以下处理：

- 主色 `#2563EB`（Blue 600），白字 5.2:1；悬停 `#1D4ED8`。深色模式提亮为 `#60A5FA` 配深色文字。
- 浅色主题背景使用**带蓝调的浅色** `#F4F7FF` / 侧边栏 `#EAF0FD`，而非中性灰，界面更通透；文字使用冷调 Slate（`#0F172A` / `#44536B`），与蓝色协调。
- 辅助天蓝 `#0EA5E9` 用于图表第二系列与装饰；强调橙 `#C2410C` 只用于「逾期」「警示」。
- 阴影带轻微蓝调（`rgba(30,58,138,…)`），避免灰黑阴影让界面发脏。

### 2.3 标签色板（12 色）

`teal · blue · indigo · violet · pink · red · orange · amber · lime · green · cyan · slate`，每色提供 `--tag-<色>-fg`（文字 / 圆点）与 `--tag-<色>-bg`（胶囊底）两值，浅深各一套。子标签默认继承父标签颜色（SRS FR-TAG-05）。

### 2.4 优先级

单选框边框颜色表示优先级：高 `--priority-high`（红）、中 `--priority-medium`（橙）、低 `--priority-low`（青，避免与蓝色主色混淆）、无 = 默认边框。**同时**在详情面板和悬停提示中以文字标出优先级，不只依赖颜色。

## 3 字体

ui-ux-pro-max 推荐 Plus Jakarta Sans（friendly / modern / productivity）。由于其**不含中文字形**，且桌面应用需离线可用、控制安装包体积，改用 Windows 系统字体栈，保持同样的现代无衬线气质：

```
"Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI", "PingFang SC", "Noto Sans SC", system-ui, sans-serif
```

| 令牌 | 值 | 用途 |
|---|---|---|
| `--text-xs` | 12 px | 时间、计数、标签胶囊（最小字号） |
| `--text-sm` | 13 px | 次要文本、表单说明 |
| `--text-base` | 14 px | 正文、列表标题（Windows Fluent 桌面正文标准） |
| `--text-md` | 16 px | 面板 / 对话框标题 |
| `--text-lg` | 20 px | 页面标题 |
| `--text-xl` | 28 px | 统计大数字 |
| `--text-2xl` | 36 px | 悬浮窗数字 |

行高：正文 1.5，标题 1.25。数字统一使用 `font-variant-numeric: tabular-nums`，避免计数变化时抖动。

> 与 ui-ux-pro-max "正文 16px" 规则的差异：该规则针对网页 / 移动端；桌面工具在 100% 缩放下以 14px 为正文标准，并通过系统缩放（100%–200%）放大，最小字号仍保持 ≥ 12px。

## 4 间距、尺寸、圆角、阴影

- 间距：4 px 基准（`--space-1` … `--space-12`）。列表行内边距 12 px，面板内边距 16–24 px，分组间距 24 px。
- 尺寸：待办行高 44 px（满足 ≥ 44 px 点击区域）；圆形单选框可视 18 px、点击区域 32 px；按钮 32 px；快速输入框 40 px；侧边栏 240 px；详情面板 360 px；悬浮窗 64 px。
- 圆角：控件 6 px、卡片 / 面板 8 px、对话框 12 px、胶囊与单选框全圆。
- 阴影：仅用于浮层（菜单、对话框、悬浮窗、Toast），列表与面板用边框分隔而非阴影。

## 5 图标

- 使用 **Lucide** 图标（与 shadcn/ui 一致），描边 1.75 px，尺寸 16 / 20 px。原型中以内联 SVG 实现。
- 禁止 emoji 作为图标。
- 纯图标按钮必须有 `aria-label` 与悬停提示（tooltip）；装饰性图标 `aria-hidden="true"`。
- 托盘图标需提供浅色 / 深色任务栏两版（SRS IR-04），使用单色剪影。

## 6 动效

| 场景 | 时长 | 缓动 | 说明 |
|---|---|---|---|
| hover / 按下 | 120 ms | ease-out | 背景色变化 |
| 面板 / 弹层进入 | 200 ms | ease-out | 透明度 + 4–8 px 位移 |
| 面板 / 弹层退出 | 150 ms | ease-in | 退出比进入快 |
| 勾选完成 | 300 ms | ease-out | 单选框填充 + 对勾描边 → 标题删除线 → 约 1 s 后移入"已完成"分组 |
| Toast（撤销提示） | 200 ms 进 / 5 s 停留 | ease-out | 底部居中 |

`prefers-reduced-motion: reduce` 时所有时长归零（`tokens.css` 已内置）；勾选完成仍立即给出状态变化。

### 7.2 待办行

`[单选框] 标题 ……… [循环图标][提醒图标] 时间 · [标签胶囊…]`
- 第一行：标题（单行省略），右侧为元信息；第二行（可选）：备注首行，`--text-sm` `--foreground-muted`。
- 逾期日期使用 `--accent`，并带"逾期"文字，不只依赖颜色。
- 悬停：`--surface-hover`；选中（打开详情）：`--surface-selected` + 左侧 2 px 主色指示条。

**排序与拖拽**（v1.6，FR-TODO-06）：
- 今天 / 计划 / 全部 / 标签列表的标题栏右侧放排序下拉（§7.9 Select），选项写成"按截止时间 / 手动排序 / 按优先级 / 按创建时间 / 按标题"，一眼看出是排序而不是筛选；每个列表各自记忆。已完成、回收站、搜索结果顺序固定，不显示。
- 只有"手动排序"时可拖拽：悬停行左侧外边距出现 14 px 拖拽手柄（`--foreground-subtle`）；拖动中原行 40% 不透明，落点用行上 / 下沿 2 px 主色内阴影指示。只能在同一分组内移动（跨分组的位置由日期决定），跨组时显示禁止光标。
- 键盘：选中行按 `Alt+↑ / Alt+↓` 与相邻项交换。

**窄宽度标题栏**（v1.8，#22 方案 1"两行工具条"）：中间列不足 640 px（例如窗口不大又打开了详情面板）时，标题与说明独占第一行，范围切换、显示已完成、排序等控件整体换到第二行；控件内文字不换行，标签路径过长时省略号截断。用容器查询（`.main` 为容器）实现，与窗口宽度无关。

### 7.3 标签胶囊

高度 20 px、水平内边距 8 px、`--text-xs`、全圆角，左侧 6 px 色点；列表中最多显示 2 个，其余以 "+N" 表示，悬停显示完整路径。

### 7.4 侧边栏

智能视图（今天 / 计划 / 全部 / 已完成 / 回收站）+ 分隔线 + 标签树（可折叠，缩进 16 px / 级）+ 底部（统计、标签管理、设置）。每项右侧显示计数徽标（`--foreground-subtle`，`tabular-nums`）。

**折叠**（v1.4）：
- 折叠按钮固定在 **侧边栏最底部**（"设置"下方，以分隔线隔开），展开时显示"收起侧边栏 · Ctrl+B"，折叠后为图标栏底部的展开图标；快捷键 `Ctrl+B`；按钮带 `aria-expanded` 与"收起 / 展开侧边栏（Ctrl+B）"提示。标题栏与页面标题前不放折叠按钮。
- 折叠后不是完全隐藏，而是收成 **56 px 图标栏**（`--size-rail`）：保留智能视图与底部入口（20 px 图标），隐藏标签树；名称与数量通过悬停提示和读屏标签提供；"今天"在图标右上角显示主色数量角标；当前项左侧有 3 px 主色指示条。
- 折叠状态保存在设置中，重启后保持；宽度切换有 200 ms 过渡（尊重"减少动画"）。

### 7.8 更新（UI-17）

> v1.2：配合 SRS v1.1 F10 新增。原则是**低打扰**：不弹模态窗打断用户，只在用户主动查看时展示详情。

| 位置 | 内容 |
|---|---|

| 安装中 | 居中对话框：图标 + "正在安装 XTodoY x.y.z…" + 不确定进度条，说明已完成更新前备份 |
| 更新后 | 主列表顶部信息横幅"已更新到 XTodoY x.y.z · 查看更新内容"，可关闭，只显示一次 |
| 托盘菜单 | 顶部加主色一行："新版本 x.y.z 可用"或"重启以完成更新"；常驻「检查更新」；就绪时「退出」改为「退出并安装更新」 |
| 系统通知 | 每个版本最多一次："XTodoY x.y.z 可以更新了"（查看详情 / 稍后）；下载完成："更新已就绪"（立即重启 / 稍后） |

原型中可用顶部工具条的"更新演示"下拉直接切换以上状态。

### 7.9 下拉选择

不使用原生 `<select>`（展开后的列表由系统绘制，无法跟随主题）。按 ui-ux-pro-max 对 shadcn 栈的建议，使用"触发按钮 + 当前值 + 选项列表"结构的 Select 组件（应用基于 Radix Select）：

| 部分 | 规范 |
|---|---|
| 触发按钮 | 高 32 px、最小宽 140 px，`--control-border` 边框、`--radius-sm`；右侧 14 px 下箭头，展开时旋转 180°，边框变为主色 |

### 7.10 需重启生效的设置

> v1.5：配合 SRS v1.1.2「硬件加速」开关新增。

- 设置 › 外观 新增「硬件加速」开关（默认关闭），说明文字写明收益与代价："滚动与动画更流畅 / 关闭可减少约 10–20 MB 常驻内存"，并注明"修改后需重启"。
- 开关状态与本次运行的实际状态不一致时，在该开关下方插入一行**重启提示**：`--primary-soft` 底、`--primary-soft-foreground` 文字，与其他设置项相同的两行结构——第一行为标题"重启后生效"（前置 14 px info 图标，图标与文字垂直居中），第二行为说明当前实际状态；右侧主按钮「立即重启」。改回原值后提示自动消失。提示行带 `role="status"`，读屏可感知。
- 不弹对话框、不自动重启——用户可继续修改其他设置，稍后再重启。

### 7.11 快捷键录制与数据设置

> v1.6：配合 P6（FR-SET-06~08）。

- **快捷键录制**：设置 › 通用「快速新建快捷键」右侧是 140 px 宽的按钮，显示当前组合（`<kbd>`，等宽数字字体），未设置时显示"未设置"。单击进入录制态：主色边框 + 3 px `--primary-soft` 外发光，文字"请按下组合键…"；按下合法组合（含 Ctrl / Alt / Win 之一 + 字母、数字或功能键）即保存，Esc 取消。不合法或被其他程序占用时，在说明行用 `--destructive` 显示原因（`role="alert"`），不保存。已设置时右侧有「关闭」幽灵按钮。
